# Decentralized Signal Detection via Expectation Propagation Algorithm for Uplink Massive MIMO Systems 

Zhenyu Zhang ${ }^{(D)}$, Hua Li ${ }^{(D)}$, Yuanyuan Dong ${ }^{(D)}$, Xiyuan Wang, and Xiaoming Dai ${ }^{(D)}$


#### Abstract

The existing centralized antenna array architecture and the corresponding centralized baseband processing based signal detection algorithms incur huge burden on the raw baseband data rates and chip input/output bandwidth for massive multipleinput multiple-output (MIMO) systems. In this paper, we propose a novel decentralized baseband processing based signal detection under the framework of the expectation propagation algorithm (EPA) for uplink massive MIMO systems. This architecture partitions the base station antennas into multiple independent antenna clusters, each associated with analog and digital modulation circuitry, independent radio-frequency chains, and computing hardwares. The antenna clusters only access local channel state information and require low communication bandwidth. In the proposed scheme, the decentralized processing unit executes local channel estimation and signal detection, and delivers the partial message to the centralized processing unit parallelly, where the message contains the local means and variances iteratively updated by the EPA detector from each antenna cluster. The centralized processing unit operates the message fusion based on the proposed message fusion rule for decoding operation. Simulation results illustrate that the proposed decentralized EPA signal detection approaches the conventional centralized one with marginal computational complexity overhead when the number of antenna clusters is small, and outperforms the state-of-the-art decentralized counterparts.


Index Terms-Massive multiple-input multiple-output (MIMO), antenna cluster, decentralized signal detection, expectation propagation algorithm (EPA), message fusion.

## I. Introduction

MASSIVE multiple-input multiple-output (MIMO) system is a critical technology for the fifth generation ( 5 G ) wireless communication systems [1], [2] due to its significant gains in spectral efficiency, energy efficiency, link reliability, latency, and coverage compared with the traditional MIMO system [3]. Massive MIMO systems deploy tens to hundreds of active antenna elements at the base station (BS) to simultaneously

[^0]serve tens of user equipments in the same frequency resource. However, the deployments of practical massive MIMO systems with large-scale antenna arrays and the BS centralized baseband processing result in huge implementation challenges, such as the excessively high computational complexity, raw baseband data rates, and chip input/output bandwidth. The excessively high amount of raw baseband date must be transferred between the baseband processing unit and the radio-frequency (RF) chains at the BS [4]. For example, in a 256 -antennas massive MIMO system with 80 MHz bandwidth and 12-bit analog-to-digital converters, the raw baseband data rates exceed $1 \mathrm{Tbit} / \mathrm{s}$. Such high data rates result in raw baseband data stream exceeding the bandwidth of the existing high-speed interconnects, such as the common public radio interface (CPRI), and place huge burden on the hardware implementations in practice [4].

In practical massive MIMO systems, the existing signal detection schemes are normally relied on centralized baseband processing in a single computing fabric, such as linear zero-forcing (ZF) and minimum mean square error (MMSE) detectors. These centralized detection schemes require the full channel state information (CSI) and full received signal at the BS, which results in high-rate raw baseband data streams sampled from large amount of RF chains at the BS and the centralized processing unit must transmit or process these data streams. To solve the above-mentioned issues, decentralized baseband processing architecture for the massive MIMO systems has been proposed recently [4]-[10]. In the decentralized massive MIMO systems, the large-scale antennas embedded on a single BS are partitioned into multiple independent antenna clusters. Each antenna cluster is associated with a decentralized processing unit which includes the local channel estimation (CHEST) module and local detector. A centralized processing unit then fuses the message generated by each antenna cluster and delivers the fused message to the decoder for decoding. The decentralized scheme provides a flexible and scalable antenna architecture in which the antennas of each cluster can be flexibly allocated, rather than the complete system redesign for the conventional centralized massive MIMO architecture when increasing the number of antennas at the BS [11].

Various decentralized baseband processing based signal detection algorithms [4]-[10] have been proposed recently to mitigate the bandwidth bottlenecks of centralized massive MIMO architectures, and enable parallel baseband processing across BS antennas on multiple computing fabrics [10]. In
decentralized baseband processing scheme, each antenna cluster is associated with local computing fabrics that carry out the necessary RF and baseband processing tasks in a decentralized and parallel manner. Decentralized conjugate gradient (CG) [5] based and decentralized alternating direction method of multipliers (ADMM) [4], [6] based signal detection schemes were proposed to reduce the computational complexity of the linear decentralized MMSE detection. These decentralized detectors carry out the centralized processing by combining the matched filter output, Gram matrix, or some intermediate variables. Reference [7] proposed a decentralized coordinate descent (CD) based data detection to approximate the traditional decentralized MMSE detection for computational complexity reduction. The authors in [8]-[10] proposed a parallel detection relying on large-MIMO approximate message passing (LAMA) method. In these two methods, the centralized processing unit fuses the local estimations to form a global estimation via a weighted sum operation [7]-[10]. However, all these algorithms exhibit only comparable performance as the decentralized MMSE detection, and the bit error rate (BER) performance is unsatisfactory for the massive MIMO systems with large number of antenna clusters.

In this paper, we propose a novel decentralized signal detection scheme under the framework of expectation propagation algorithm (EPA) [12], [13] for the uplink massive MIMO systems. The EPA is a type of approximate message passing algorithm which approximates the symbol belief by a Gaussian probability density function (PDF) and simplifies the complicated message passing rules by mean and variance propagation. In the proposed decentralized scheme, the antennas at the BS are partitioned into multiple independent antenna clusters. In each cluster, the decentralized processing unit carries out local EPA detection according to the local CSI (received from the local CHEST module) and the local received signal. The centralized processing unit collects the means and variances propagated from each antenna cluster and computes the fused means and variances via the product principle of univariate Gaussian PDFs. The log-likelihood ratio (LLR) is updated iteratively based on the fused means and variances for decoding. To evaluate the feasibility of the proposed decentralized EPA architecture, we perform simulations for the uplink massive MIMO systems. Simulation results illustrate that the proposed decentralized EPA signal detection approaches the performance of the centralized one with marginal computational complexity overhead, and outperforms the state-of-the-art decentralized counterparts especially for large number of antenna clusters.

The remainder of this paper is organized as follows. Section II provides the decentralized uplink massive MIMO system model. Section III details the proposed decentralized EPA signal detection as well as the computational complexity analysis. Simulation results are presented in Section IV. Finally, conclusions are drawn in Section V.

## II. System Model

We consider an uplink massive MIMO system where $K$ single-antenna user equipments transmit signal to the BS with $N(N \gg K)$ antenna elements in the same frequency resource simultaneously. The source bits $\mathbf{b}$ for all users are encoded by a channel encoder and permuted by a random interleaver, producing the coded and interleaved bits $\mathbf{c}$. The bit stream is mapped into a complex constellation $\mathcal{A}$ with cardinality $|\mathcal{A}|=2^{Q}$ which results in the transmitted signal vector $\mathbf{x}=\left[x_{1}, x_{2}, \ldots, x_{K}\right]^{T}$. Each transmitted symbol $x_{k}$ is associated with $Q$ bits $c_{k}^{q}$ where $q=1,2, \ldots, Q$. The average power of transmitted symbol is normalized to unit $\mathrm{E}\left[\left|x_{k}\right|^{2}\right]=1$. The baseband input-output relation of the uplink channel is modeled as

$$
\begin{equation*}
\mathbf{y}=\mathbf{H} \mathbf{x}+\mathbf{n}, \tag{1}
\end{equation*}
$$

where $\mathbf{y}$ is the received signal, $\mathbf{H}$ is the Rayleigh flat fading channel matrix whose entries are independent and identically distributed with zero mean and unit variance, and $\mathbf{n}$ denotes the complex additive white Gaussian noise (AWGN) vector with zero mean and covariance matrix $\sigma^{2} \mathbf{I}$. Perfect CSI is assumed to be available at the receiver and the signal-to-noise ratio (SNR) is defined as $\mathrm{SNR}=K / \sigma^{2}$.

In decentralized massive MIMO systems, $N$ antennas at the BS are partitioned into $C$ independent antenna clusters and the partition is assumed to be uniform. Each antenna cluster equips $M=N / C$ antennas and a decentralized processing unit which contains a local RF circuitry, local CHEST module, local detector, and relevant computing hardwares. By partitioning the channel matrix row-wise into blocks as $\mathbf{H}=\left[\mathbf{H}_{1}^{T}, \mathbf{H}_{2}^{T}, \ldots, \mathbf{H}_{C}^{T}\right]^{T}$, the received signal vector as $\mathbf{y}=\left[\mathbf{y}_{1}^{T}, \mathbf{y}_{2}^{T}, \ldots, \mathbf{y}_{C}^{T}\right]^{T}$, and the noise vector as $\mathbf{n}=\left[\mathbf{n}_{1}^{T}, \mathbf{n}_{2}^{T}, \ldots, \mathbf{n}_{C}^{T}\right]^{T}$, the received signal at the $c$ th antenna cluster is denoted as

$$
\begin{equation*}
\mathbf{y}_{c}=\mathbf{H}_{c} \mathbf{x}+\mathbf{n}_{c} . \tag{2}
\end{equation*}
$$

When the number of antenna clusters is $C=1$, the decentralized massive MIMO system degenerates into the conventional centralized massive MIMO system.

Soft-input soft-output iterative detection and decoding (IDD) scheme adopts an iterative procedure in which the detector and decoder exchange the extrinsic information iteratively to extract the extrinsic LLR. The extrinsic LLR $L_{e}\left(c_{k}^{q}\right)$ of bit $c_{k}^{q}$ generated

![](https://cdn.mathpix.com/cropped/2847ca2d-5d15-4a4a-bad7-3708944607a4-3.jpg?height=544&width=884&top_left_y=223&top_left_x=124)
Fig. 2. Factor graph of decentralized EPA.

by the detector is computed as

$$
\begin{equation*}
L_{e}\left(c_{k}^{q}\right)=\ln \frac{p\left(c_{k}^{q}=1 \mid \mathbf{y}\right)}{p\left(c_{k}^{q}=0 \mid \mathbf{y}\right)}-L_{a}\left(c_{k}^{q}\right) \tag{3}
\end{equation*}
$$

where $L_{a}\left(c_{k}^{q}\right)$ is the a priori LLR fed back from the decoder. The block diagram of the decentralized baseband processing based EPA receiver model is illustrated in Fig. 1.

## III. Decentralized Signal Detection Based on Expectation Propagation Algorithm

## A. Factor Graph Model

The signal processing by EPA can be viewed as an instance of the sum-product algorithm [12] which operates the message passing in a factor graph. The joint distribution $p(\mathbf{x}, \mathbf{y})$ can be factorized into [14], [15]

$$
\begin{equation*}
p(\mathbf{x}, \mathbf{y})=p(\mathbf{x}) p(\mathbf{y} \mid \mathbf{x})=\prod_{k} p\left(x_{k}\right) \prod_{n} f_{n}\left(y_{n} \mid \mathbf{x}\right), \tag{4}
\end{equation*}
$$

where $p(\mathbf{x})$ denotes the a priori distribution of $\mathbf{x}$, and the likelihood function $f_{n}\left(y_{n} \mid \mathbf{x}\right)$ is computed by

$$
\begin{equation*}
f_{n}\left(y_{n} \mid \mathbf{x}\right)=\frac{1}{\pi \sigma^{2}} \exp \left(-\frac{\left|y_{n}-\sum_{k} h_{n, k} x_{k}\right|^{2}}{\sigma^{2}}\right) \tag{5}
\end{equation*}
$$

where the $n$th row and $k$ th column element in the CSI matrix $\mathbf{H}$ is denoted by $h_{n, k}$. The factorization in (4) can be represented by the factor graph. A factor graph example of decentralized EPA is illustrated in Fig. 2, where the antenna configuration is $N \times K=8 \times 6$ and $C=2$. The variable nodes (VNs), factor nodes (FNs), and cloning nodes (CNs) represent the users, likelihood functions, and constellation mapping constraints, respectively. The inner iteration denotes the message passing between VNs and FNs iteratively, and the outer iteration represents the IDD procedure. The number of inner and outer iterations are denoted by $i$ and $t$, respectively. The maximum number of inner and outer iterations are denoted by $I_{\text {max }}$ and $T_{\text {max }}$, respectively.

## B. Decentralized Expectation Propagation Algorithm

The key idea of the EPA is to approximate a (often intractable) distribution $p$ with another tractable distribution $q$ which is

![](https://cdn.mathpix.com/cropped/2847ca2d-5d15-4a4a-bad7-3708944607a4-3.jpg?height=347&width=899&top_left_y=214&top_left_x=1033)
Fig. 3. Message passing rules between VN and FN. (a) Message passing from VN to FN. (b) Message passing from FN to VN.

constrained to lie in a family of simple distribution set $\Phi$ through distribution projection. Let $\Phi$ be some set of distributions and the projection of a distribution $p$ into the set $\Phi$ is represented as [15]

$$
\begin{equation*}
\operatorname{Proj}_{\Phi}(p)=\arg \min _{q \in \Phi} D_{\mathrm{KL}}(p \| q) \tag{6}
\end{equation*}
$$

where $D_{\mathrm{KL}}(p \| q)$ denotes the Kullback-Leibler (KL) divergence which is an asymmetric measure of dissimilarity between two probability distributions $p$ and $q$.

In the decentralized processing unit, we consider the decentralized EPA signal detection in the $c$ th antenna cluster with $M$ antennas and $K$ users. The $m$ th element in the local received signal $\mathbf{y}_{c}$ is $y_{c, m}$ while the $m$ th row and $k$ th column element in the local CSI matrix $\mathbf{H}_{c}$ is $h_{c, m k}$. Let $\mu_{x_{k} \rightarrow f_{c, m}}^{i, t}\left(x_{k}\right)$ denote the message passing from VN $x_{k}$ to FN $f_{c, m}$ at the $i$ th inner iteration and the $t$ th outer iteration of the $c$ th antenna cluster, and $\mu_{f_{c, m} \rightarrow x_{k}}^{i, t}\left(x_{k}\right)$ represent the message passing in the opposite direction. The detailed description of message passing rules between VN and FN is depicted in Fig. 3. The message passing rules are expressed as [12], [14]

$$
\begin{align*}
& \mu_{x_{k} \rightarrow f_{c, m}}^{i, t}\left(x_{k}\right)=\mu_{\phi_{k} \rightarrow x_{k}}^{t}\left(x_{k}\right) \prod_{m^{\prime} \neq m} \mu_{f_{c, m^{\prime}} \rightarrow x_{k}}^{i-1, t}\left(x_{k}\right)  \tag{7}\\
& \mu_{f_{c, m} \rightarrow x_{k}}^{i, t}\left(x_{k}\right)=\sum_{\mathbf{x} \backslash x_{k}} f_{c, m}\left(y_{c, m} \mid \mathbf{x}\right) \prod_{k^{\prime} \neq k} \mu_{x_{k^{\prime}} \rightarrow f_{c, m}}^{i, t}\left(x_{k^{\prime}}\right) \tag{8}
\end{align*}
$$

where $\mathbf{x} \backslash x_{k}$ represents all the enumerations of $\mathbf{x}$ except for $x_{k}$, and $\mu_{\phi_{k} \rightarrow x_{k}}^{t}\left(x_{k}\right)=p\left(x_{k}\right)$ is computed as

$$
\begin{equation*}
\mu_{\phi_{k} \rightarrow x_{k}}^{t}\left(x_{k}\right)=\prod_{q} \frac{\exp \left(c_{k}^{q} L_{a}^{t}\left(c_{k}^{q}\right)\right)}{1+\exp \left(L_{a}^{t}\left(c_{k}^{q}\right)\right)} \tag{9}
\end{equation*}
$$

which denotes the a priori probability of $x_{k}$ fed back from the decoder at the $t$ th outer iteration. The a priori message $\mu_{\phi_{k} \rightarrow f_{k}}^{t}\left(x_{k}\right)$ is shared by all the antenna clusters, and $L_{a}^{0}\left(c_{k}^{q}\right)=0$ is initialized since there is no a priori information fed back from the decoder at the initial iteration. The symbol belief in the $c$ th antenna cluster, i.e., the a posteriori probability of $x_{k}$, is calculated as [14]

$$
\begin{equation*}
p^{i, t}\left(x_{k}\right)=\frac{1}{Z} \mu_{\phi_{k} \rightarrow x_{k}}^{t}\left(x_{k}\right) \prod_{m} \mu_{f_{c, m} \rightarrow x_{k}}^{i-1, t}\left(x_{k}\right) \tag{10}
\end{equation*}
$$

where $Z$ is the normalization constant. According to (7) and (10), the message $\mu_{x_{k} \rightarrow f_{c, m}}^{i, t}\left(x_{k}\right)$ is rewritten as

$$
\begin{equation*}
\mu_{x_{k} \rightarrow f_{c, m}}^{i, t}\left(x_{k}\right)=\frac{Z p^{i, t}\left(x_{k}\right)}{\mu_{f_{c, m} \rightarrow x_{k}}^{i-1, t}\left(x_{k}\right)} . \tag{11}
\end{equation*}
$$

Since the symbols are taken on values in the discrete constellation set $\mathcal{A}$, the computation of $\mu_{f_{c, m} \rightarrow x_{k}}^{i, t}\left(x_{k}\right)$ in (8) requires exponential time to marginalize out the vector $\mathbf{x} \backslash x_{k}$. To reduce the computational complexity of message passing rules, the messages $\mu_{x_{k} \rightarrow f_{c, m}}^{i, t}\left(x_{k}\right)$ and $\mu_{f_{c, m} \rightarrow x_{k}}^{i, t}\left(x_{k}\right)$ are approximated as complex Gaussian PDFs as $\mathcal{C} \mathcal{N}\left(x_{k} ; x_{x_{k} \rightarrow f_{c, m}}^{i, t}, v_{x_{k} \rightarrow f_{c, m}}^{i, t}\right)$ and $\mathcal{C} \mathcal{N}\left(x_{k} ; x_{f_{c, m} \rightarrow x_{k}}^{i, t}, v_{f_{c, m} \rightarrow x_{k}}^{i, t}\right)$, respectively. The symbol belief $p^{i, t}\left(x_{k}\right)$ is also approximated as a continuous complex Gaussian PDF, which results in an approximation $\hat{p}^{i, t}\left(x_{k}\right)= \mathcal{C} \mathcal{N}\left(x_{k} ; \hat{x}_{k}^{i, t}, \hat{v}_{k}^{i, t}\right)$. The mean and variance of the approximate symbol belief $\hat{p}^{i, t}\left(x_{k}\right)$ are obtained by moment matching [14]

$$
\begin{align*}
\hat{x}_{k}^{i, t} & =\sum_{\alpha \in \mathcal{A}} \alpha p^{i, t}\left(x_{k}=\alpha\right),  \tag{12}\\
\hat{v}_{k}^{i, t} & =\sum_{\alpha \in \mathcal{A}}\left|\alpha-\hat{x}_{k}^{i, t}\right|^{2} p^{i, t}\left(x_{k}=\alpha\right), \tag{13}
\end{align*}
$$

where $\alpha$ is the constellation symbol in the set $\mathcal{A}$. Since the Gaussian distribution can be fully characterized by the mean and variance, the complicated message passing rule in (11) can be simplified into mean and variance parameter update after the Gaussian approximations are adopted. Based on (11) and the approximate symbol belief we obtain

$$
\begin{equation*}
\mu_{x_{k} \rightarrow f_{c, m}}^{i, t}\left(x_{k}\right) \propto \frac{p^{i, t}\left(x_{k}\right)}{\mu_{f_{c, m} \rightarrow x_{k}}^{i-1, t}\left(x_{k}\right)} \approx \frac{\hat{p}^{i, t}\left(x_{k}\right)}{\mu_{f_{c, m} \rightarrow x_{k}}^{i-1, t}\left(x_{k}\right)}, \tag{14}
\end{equation*}
$$

and it is denoted as

$$
\begin{equation*}
\mathcal{C N}\left(x_{k} ; x_{x_{k} \rightarrow f_{c, m}}^{i, t}, v_{x_{k} \rightarrow f_{c, m}}^{i, t}\right) \propto \frac{\mathcal{C N}\left(x_{k} ; \hat{x}_{k}^{i, t}, \hat{v}_{k}^{i, t}\right)}{\mathcal{C N}\left(x_{k} ; x_{f_{c, m} \rightarrow x_{k}}^{i-1, t}, v_{f_{c, m} \rightarrow x_{k}}^{i-1, t}\right)} \tag{15}
\end{equation*}
$$

The means and variances propagated from VNs to FNs are thus computed respectively as [16]

$$
\begin{align*}
v_{x_{k} \rightarrow f_{c, m}}^{i, t} & =\left(\frac{1}{\hat{v}_{k}^{i, t}}-\frac{1}{v_{f_{c, m} \rightarrow x_{k}}^{i-1, t}}\right)^{-1}  \tag{16}\\
x_{x_{k} \rightarrow f_{c, m}}^{i, t} & =v_{x_{k} \rightarrow f_{c, m}}^{i, t}\left(\frac{\hat{x}_{k}^{i, t}}{\hat{v}_{k}^{i, t}}-\frac{x_{f_{c, m} \rightarrow x_{k}}^{i-1, t}}{v_{f_{c, m} \rightarrow x_{k}}^{i-1, t}}\right) \tag{17}
\end{align*}
$$

where the initial value $x_{f_{c, m} \rightarrow x_{k}}^{0, t}=0$ and $v_{f_{c, m} \rightarrow x_{k}}^{0, t}=+\infty$ can be set at the initial inner iteration. Since $\mu_{f_{c, m} \rightarrow x_{k}}^{i, t}\left(x_{k}\right)$ has been approximated as a complex Gaussian PDF, the calculation of (8) can be solved by integration [14], [17]

$$
\begin{align*}
\mu_{f_{c, m} \rightarrow x_{k}}^{i, t}\left(x_{k}\right) & =\int_{\mathbf{x} \backslash x_{k}} f_{c, m}\left(y_{c, m} \mid \mathbf{x}\right) \prod_{k^{\prime} \neq k} \mu_{x_{k^{\prime}} \rightarrow f_{c, m}}^{i, t}\left(x_{k^{\prime}}\right) \\
& =\mathcal{C N}\left(x_{k} ; x_{f_{c, m} \rightarrow x_{k}}^{i, t}, v_{f_{c, m} \rightarrow x_{k}}^{i, t}\right) \tag{18}
\end{align*}
$$

where the means and variances propagated from FNs to VNs are computed respectively as

$$
\begin{align*}
x_{f_{c, m} \rightarrow x_{k}}^{i, t} & =\frac{1}{h_{c, m k}}\left(y_{c, m}-\sum_{k^{\prime} \neq k} h_{c, m k^{\prime}} x_{x_{k^{\prime}} \rightarrow f_{c, m}}^{i, t}\right),  \tag{19}\\
v_{f_{c, m} \rightarrow x_{k}}^{i, t} & =\frac{1}{\left|h_{c, m k}\right|^{2}}\left(\sum_{k^{\prime} \neq k}\left|h_{c, m k^{\prime}}\right|^{2} v_{x_{k^{\prime}} \rightarrow f_{c, m}}^{i, t}+\sigma^{2}\right) . \tag{20}
\end{align*}
$$

The means and variances are updated iteratively between VNs and FNs until the maximum number of inner iterations is reached. After inner iterations, the VNs collect the message passed from the FNs in each antenna cluster, and the message passed from VNs to CNs is computed as

$$
\begin{equation*}
\mu_{x_{k} \rightarrow \phi_{k}}^{t, c}\left(x_{k}\right)=\prod_{m} \mu_{f_{c, m} \rightarrow x_{k}}^{I_{\max }, t}\left(x_{k}\right), \tag{21}
\end{equation*}
$$

which is the multiplication of all the incoming messages $\mu_{f_{c, m} \rightarrow x_{k}}^{I_{\text {max }}, t}\left(x_{k}\right)$. The message $\mu_{x_{k} \rightarrow \phi_{k}}^{t, c}\left(x_{k}\right)$ is modeled as a complex Gaussian $\operatorname{PDF} \mathcal{C} \mathcal{N}\left(x_{k} ; \tilde{x}_{k}^{t, c}, \tilde{v}_{k}^{t, c}\right)$ whose mean and variance are calculated respectively as [16]

$$
\begin{align*}
& \tilde{v}_{k}^{t, c}=\left(\sum_{m} \frac{1}{v_{f_{c, m} \rightarrow x_{k}}^{I_{\max }, t}}\right)^{-1},  \tag{22}\\
& \tilde{x}_{k}^{t, c}=\tilde{v}_{k}^{t, c}\left(\sum_{m} \frac{x_{f_{c, m} \rightarrow x_{k}}^{I_{\max }, t}}{v_{f_{c, m} \rightarrow x_{k}}^{I_{\max }, t}}\right) . \tag{23}
\end{align*}
$$

Note that the means and variances of the multiplicative message $\prod_{m} \mu_{f_{c, m} \rightarrow x_{k}}^{i-1, t}\left(x_{k}\right)$ in (10) can be calculated based on (22) and (23) by replacing the superscript $I_{\text {max }}$ with $i-1$.

In the centralized processing unit, the messages from all the $C$ antenna clusters are fused by the proposed message fusion rule. Integrating all the means $\tilde{x}_{k}^{t, c}$ and variances $\tilde{v}_{k}^{t, c}$ propagated from each antenna cluster, the fused message $\mu_{x_{k} \rightarrow \phi_{k}}^{t}\left(x_{k}\right)= \mathcal{C} \mathcal{N}\left(x_{k} ; \tilde{x}_{k}^{t}, \tilde{v}_{k}^{t}\right)$ are obtained based on the multiplication of all the incoming message $\mu_{x_{k} \rightarrow \phi_{k}}^{t, c}\left(x_{k}\right)$, and the mean and variance are computed respectively as [16]

$$
\begin{align*}
& \tilde{v}_{k}^{t}=\left(\sum_{c} \frac{1}{\tilde{v}_{k}^{t, c}}\right)^{-1}=\left(\sum_{c} \sum_{m} \frac{1}{v_{f_{c, m} \rightarrow x_{k}}^{I_{\max }, t}}\right)^{-1},  \tag{24}\\
& \tilde{x}_{k}^{t}=\tilde{v}_{k}^{t}\left(\sum_{c} \frac{\tilde{x}_{k}^{t, c}}{\tilde{v}_{k}^{t, c}}\right)=\tilde{v}_{k}^{t}\left(\sum_{c} \sum_{m} \frac{x_{f_{c, m} \rightarrow x_{k}}^{I_{\max }, t}}{v_{f_{c, m} \rightarrow x_{k}}^{I_{\max }, t}}\right) . \tag{25}
\end{align*}
$$

Based on the fused message $\mu_{x_{k} \rightarrow \phi_{k}}^{t}\left(x_{k}\right)$, the updated symbol belief $\beta^{t}\left(x_{k}\right)$ is generated as [14]

$$
\begin{equation*}
\beta^{t}\left(x_{k}\right)=\frac{1}{Z} \mu_{\phi_{k} \rightarrow x_{k}}^{t}\left(x_{k}\right) \mathcal{C} \mathcal{N}\left(x_{k} ; \tilde{x}_{k}^{t}, \tilde{v}_{k}^{t}\right), \tag{26}
\end{equation*}
$$

where $Z$ is the normalization constant. The extrinsic LLR generated by the decentralized EPA detector is computed as

$$
\begin{equation*}
L_{e}^{t}\left(c_{k}^{q}\right)=\ln \frac{\sum_{x_{k} \in \mathcal{A}_{q}^{1}} \beta^{t}\left(x_{k}\right)}{\sum_{x_{k} \in \mathcal{A}_{q}^{0}} \beta^{t}\left(x_{k}\right)}-L_{a}^{t}\left(c_{k}^{q}\right), \tag{27}
\end{equation*}
$$

## C. Computational Complexity Analysis

The computational complexity analysis of the proposed decentralized EPA signal detection in terms of the required complex multiplication number is provided in this subsection. ## V. Conclusion

In this paper, we proposed a novel decentralized EPA signal detection for the uplink massive MIMO systems. This scheme
contains of a decentralized processing unit which operates the local CHEST and local EPA signal detection, as well as a centralized processing unit which carries out message fusion and LLR refining for decoding. Simulation results illustrated that the proposed decentralized EPA signal detection achieves similar performance as that of the centralized counterpart with marginal computational complexity overhead, and outperforms the state-of-the-art decentralized signal detection schemes.
